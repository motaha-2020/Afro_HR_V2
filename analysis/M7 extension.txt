# 07.60 — Location-Based Allowances, Field Allowances & Mobility Rules

ويكون مرتبطًا بـ:

**Employee + Project + Work Location + Distance + Assignment Type + Attendance + Shift + Policy**

وده مناسب جدًا لطبيعة Afro لأن الـOperations Manual عنده أصلًا **Allowances Workflow** منفصل، وفيه تجميع بيانات البدلات من المشروعات، إعداد Allowance Sheet، التحقق من الاستحقاق، ثم الإرسال للمالية.

# 07.60.4 Distance-Based Rules

الأفضل أيضًا دعم المسافة.

مثلاً:

Employee Base Location:

`Cairo HQ`

Work Site:

`Project Site`

النظام يحسب:

**Distance from Base Location**

ثم يطبق Rule.

مثلاً:

| Distance   |   Allowance |
| ---------- | ----------: |
| 0–25 km    |       0 EGP |
| 26–50 km   | 100 EGP/day |
| 51–100 km  | 200 EGP/day |
| 101–200 km | 350 EGP/day |
| >200 km    | 500 EGP/day |

وده يخلي النظام مناسب لأي توسع مستقبلي.

---

# 07.60.5 Base Location Concept

مهم جدًا تحديد:

### Employee Base Location

مثلاً:

Ahmed:

`Cairo HQ`

Mohamed:

`Alexandria Office`

Ali:

`Suez Project Office`

وبالتالي Outside Cairo لا تُحسب بالنسبة إلى القاهرة دائمًا.

بل:

> Outside Employee Base Location

مثلاً موظف أصله Alexandria ويعمل Alexandria:

لا يأخذ Outside Cairo Allowance.

لكن موظف Base Location = Cairo وذهب Alexandria:

قد يستحق.

# 07.60.9 Minimum Hours Rule

`Worked Hours >= 6`

# 07.60.12 Company Accommodation Rule

مهم جدًا منع Double Payment.

مثلاً:

`Accommodation Provided By Company = Yes`

إذن:

Accommodation Allowance:

`0`

ولو:

`Transportation Provided = Yes`

Transport Allowance:

`0`

نفس الفكرة مع:

* Hotel
* Transportation
* Meals
* Fuel

# 07.60.13 Allowance Stacking Rules

نحتاج:

**Can Combine With**

مثلاً:

Outside Cairo Allowance

يمكن دمجه مع:

✓ Night Shift Allowance
✓ Meal Allowance

لكن لا يمكن دمجه مع:

✗ Travel Per Diem

حتى لا يحصل Duplicate Benefit.
